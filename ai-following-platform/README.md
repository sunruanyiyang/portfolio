# AI Camera-Following Transport Platform

## Overview

This project was developed during an Innovation Lab activity under the guidance of an instructor.

Our team designed and built a transport platform equipped with an AI camera. The system was able to detect a person's position and automatically follow them.

The project introduced me to the relationship between sensing, computation, and physical machine behavior.

---

## My Contribution

I worked with my teammates on the development and testing of the platform.

My experience included:

- Working with the AI camera-based sensing system
- Programming the system using Micro Blocks
- Testing the platform's movement and following behavior
- Debugging the system with teammates
- Exploring how human position can be translated into machine movement

---

## Technologies

- AI Camera
- Micro Blocks
- Sensors
- Physical Computing
- Hardware Prototyping

---

## How It Works

The basic interaction process can be described as:

**Person → Camera Sensing → Position Detection → System Response → Platform Movement**

The system observes the position of a person and uses this information to determine how the platform should move.

---

## What I Learned

This project gave me hands-on experience with interactive physical systems.

More importantly, I learned how information from the physical world can be captured by sensors and converted into computational decisions and physical responses.

This experience increased my interest in human-machine interaction and interactive systems.
